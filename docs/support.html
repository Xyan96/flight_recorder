飞行记录支持

飞行记录是一款 iPad 离线记录工具。App 本体不需要账号登录，不连接后端服务器，不提供互联网信息服务，记录默认保存在用户自己的 iPad 本地。

常见问题

没有网络时可以使用吗？
可以。主要记录、保存、载入、备份导出和备份导入功能均可离线使用。

记录保存在哪里？
记录保存在 iPad App 本地数据中。删除 App 可能会同时删除本地记录。

如何备份？
打开“记录夹”，使用“导出备份”保存 JSON 备份文件。换设备或重装后可通过“导入备份”恢复。

是否需要服务器、域名或备案？
App 本体不依赖服务器或域名，也不向用户提供互联网信息服务。此网页只用于 App Store 的公开支持和隐私政策展示，不是 App 的运行依赖。

Flight Recorder Support

Flight Recorder is an offline iPad utility. The app itself does not require an account, does not connect to a backend server, does not provide an internet information service, and stores records locally on the user's iPad by default.

FAQ

Can I use it without network access?
Yes. Core recording, saving, loading, backup export, and backup import features work offline.

Where are records stored?
Records are stored in the app's local data on the iPad. Deleting the app may delete local records.

How do I back up records?
Open the record folder, export a JSON backup, and store it where you choose. You can import that backup again after reinstalling or moving to another device.

Does the app need a server, domain, or filing?
No server or domain is required for the app runtime. This website is only a public support and privacy page for App Store review and listing purposes; it is not a runtime dependency of the app.
