## Description

```text
Flight Recorder is an offline iPad utility for recording flight communication, cruise checks, fuel calculations, crew oxygen, and related notes.

The app does not require an account, backend service, runtime domain, or network connection. Records are stored locally on the user's iPad. Users can search and load local records from the record folder, and can export or import backup files when they choose.

Key features:
- Flight communication records and UTC time entries
- Cruise-check records and fuel-difference calculation
- Local captain archive number matching
- Local record folder with save, search, load, and delete
- Backup export and import
- Independent offline iPad operation
```
