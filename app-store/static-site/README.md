# 飞行记录静态支持站点

这个目录用于托管 App Store Connect 需要的公开页面，不属于 iPad App 本体，也不作为 App 后端服务。

可以托管到 GitHub Pages，也可以使用你的域名。这里的页面只用于 App Store Connect 的公开支持和隐私信息，不属于 iPad App 本体，也不作为 App 后端服务：

- `support.html`: App Store Connect 的 Support URL
- `privacy.html`: App Store Connect 的 Privacy Policy URL
- `index.html`: 简单入口页

示例 URL：

```text
https://<github-username>.github.io/flight-recorder/support.html
https://<github-username>.github.io/flight-recorder/privacy.html
https://<your-domain>/flight-recorder/support.html
https://<your-domain>/flight-recorder/privacy.html
```

提交前需要把页面中的公开支持邮箱替换为最终邮箱，或确认支持页面中的联系说明符合你的发布策略。
