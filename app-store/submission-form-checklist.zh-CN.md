# App Store Connect 表单清单

这份清单用于创建 App 记录、选择构建版本并提交审核。页面文案可能随 App Store Connect 更新略有不同，最终以网页当前显示为准。

## App 记录

| 字段 | 建议填写 |
| --- | --- |
| 平台 | iOS |
| 名称 | 飞行记录 |
| 主要语言 | 简体中文 |
| Bundle ID | com.xiazhiyuan.flightrecorder |
| SKU | flight-recorder-ios |
| 用户访问权限 | Full Access |

## App 信息

| 字段 | 建议填写 |
| --- | --- |
| 类别 | 效率 |
| 副类别 | 可留空，或按页面可选项选择最贴近的办公/效率分类 |
| 内容权利 | 不包含第三方受版权保护内容 |
| 年龄分级 | 逐项选择无/否，预期为最低年龄分级 |
| 面向儿童 | 否 |

年龄分级问卷建议：

- 卡通或幻想暴力：无
- 现实暴力：无
- 成人或暗示性主题：无
- 恐怖/惊悚主题：无
- 医疗/治疗信息：无
- 酒精、烟草、药物相关内容：无
- 赌博或竞赛：无
- 不受限制的网页访问：否
- 用户生成内容：否，应用仅保存用户自己的本地记录，不提供公开发布或社交互动

## 价格与可用范围

## App 隐私

| 问题 | 建议填写 |
| --- | --- |
| 是否收集数据 | 否 |
| 是否用于追踪 | 否 |
| 是否包含第三方广告 | 否 |
| 是否包含第三方分析 SDK | 否 |
| 是否使用 IDFA | 否 |
| 是否需要账号登录 | 否 |

说明：

```text
用户填写的飞行记录只保存在 iPad 本地。用户主动导出备份时，备份文件由用户自行选择保存或分享的位置。
```

## 出口合规

| 问题 | 建议填写 |
| --- | --- |
| 是否使用非豁免加密 | 否 |
| 是否包含自定义加密算法 | 否 |
| 是否专门用于加密通信或安全 | 否 |

项目已在 `Info.plist` 中声明：

```text
ITSAppUsesNonExemptEncryption = false
```

## 审核信息

| 字段 | 建议填写 |
| --- | --- |
| 登录账号 | 不需要账号 |
| 联系人姓名 | 待定 |
| 联系电话 | 待定 |
| 联系邮箱 | 待定 |
| 审核备注 | 使用 `app-store/connect-fields.zh-CN.md` 中的审核备注 |

审核备注重点：

- App 离线运行。
- 不需要登录。
- 不需要后端服务。
- 记录保存在 iPad 本地。
- 审核人员可直接填写测试数据、保存、打开记录夹并载入。

## 提交前必须确定

- 公开支持邮箱
- Support URL
- Privacy Policy URL
- 审核联系人姓名、电话、邮箱
- 价格
- 上架国家和地区
- 是否免费或付费
- 真机 iPad Air 第五代测试是否通过
